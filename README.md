# 图片工具箱 (Image Toolbox)

一个用 C# / WinForms 编写的 Windows 桌面工具箱，以多标签页形式集成多种图片处理功能。界面基于 WinForms，图片解码/编码基于 WPF / WIC，无需安装 .NET SDK 即可编译运行。

## 功能

界面只有两个顶层页签：

- **单图编辑**：类似 Photoshop 的**单画布 + 图层**工作流——顶部可**打开图片**或**新建**空白图（自动成为「背景」图层），左侧选择操作，操作控件在右侧，预览直接渲染到中央唯一画布；右下角是全局**图层**面板，可添加图片/新建/复制/删除/上下移/向下合并/盖印/拼合，并设置显示、混合模式与不透明度。所有操作作用于**当前选中图层**，画布显示全部图层的合成结果；调好后点「应用到图片」把结果写入当前图层（裁剪/画布/证件照/切图等改变尺寸的操作会作用于整张文档），支持**撤销/重做/复位**，最后「保存为 PNG」（保存的是合成结果）。画布支持**滚轮缩放**（以光标为中心）与**空格+拖动平移**（中键拖动同样可平移）。若当前操作结果尚未点「应用到图片」就切换操作，会先弹窗询问是否应用（应用 / 放弃 / 取消）。
- **批处理**：左侧列出批处理类工具（批量处理、批量导出）。

各操作/工具功能如下：

| 位置 | 项目 | 说明 |
| --- | --- | --- |
| 批处理 | **批量处理** | 批量转换格式（PNG/JPG/BMP/GIF/TIFF，WebP 可作输入）、缩放、旋转翻转（含 EXIF 自动校正）、重命名（模板/序号/查找替换）、加水印（文字/图片、九宫格、平铺、透明度）。 |
| 批处理 | **批量导出** | 每个文件按多个尺寸批量导出，并可打包多尺寸 `.ico` 图标。 |
| 单图编辑 | **基础调整** | 亮度 / 对比度 / 饱和度 / 色温 / 色调。 |
| 单图编辑 | **色阶** | 黑场 / 白场 / 伽马，自动色阶。 |
| 单图编辑 | **曲线** | RGB / 红 / 绿 / 蓝分通道曲线编辑。 |
| 单图编辑 | **白平衡** | 画布取点校正 / 自动白平衡。 |

| 单图编辑 | **局部调整** | 径向/线性蒙版，画布点选中心，调曝光/对比/饱和。 |

| 单图编辑 | **LUT** | 加载 .cube 3D LUT，可调强度。 |
| 单图编辑 | **风格预设** | 13 种预设滤镜 + 强度。 |

| 单图编辑 | **变换** | 对当前图层**移动**（画布拖动）/ **缩放** / **旋转**（以图层中心为基准），支持重置。 |
| 单图编辑 | **抠图** | 颜色阈值（全局）或魔术棒（连续）把相近颜色变为透明，可反转。 |
| 单图编辑 | **裁剪 / 旋转** | 框选裁剪、顺/逆时针旋转 90°、水平/垂直翻转（按钮点击即执行，可连续叠加），可「重置」回进入该操作时的状态。 |
| 单图编辑 | **画布 / 校正** | 旋转拉直（可自动裁边）、画布扩展/裁切（九宫格锚点 + 填充色）。 |

## 环境要求

- Windows 7 及以上（推荐 Windows 11）
- .NET Framework 4.x（Windows 自带，无需额外安装）
- WebP 解码依赖系统 WIC 编解码器：
  - Windows 11：内置，开箱即用
  - Windows 10：如提示无法解码，请在 Microsoft Store 安装 “WebP Image Extensions”

## 编译

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

脚本调用系统自带的旧版编译器 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，编译仓库根目录下所有 `.cs`，在仓库根目录生成 `ImageToolbox.exe`。

> 该编译器为 **C# 5**，不支持字符串插值、`?.`、表达式成员等 C# 6+ 语法。

## 运行

双击 `ImageToolbox.exe` 启动，窗口标题为“图片工具箱”。

## 扩展新工具

- **单图编辑操作**：在 `src/App/` 新建类继承 `EditOpPanel`，实现 `RenderPreview()`（用 `PreviewSource` 渲染预览）与 `BuildResult()`（用 `Source` 渲染全分辨率结果，返回 `null` 表示不可应用），需要画布交互时重写 `OnCanvasClick`/`OnCanvasSelection`/`OnBrushPoint`；默认作用于当前图层，若会改变整张文档尺寸（如裁剪/画布）则重写 `DocumentLevel => true`；然后在 `SingleEditPage` 的 `_ops` 与 `names` 数组里注册：

  ```csharp
  public class MyOp : EditOpPanel
  {
      public MyOp() { EditOpUi.Title(this, "我的操作", 10); /* 搭建控件 */ }
      public override Bitmap RenderPreview() { return null; }
      public override Bitmap BuildResult() { return null; }
  }
  ```

- **批处理工具**：在 `src/Pages/` 新建类继承 `ToolPage`，在构造函数里搭建界面，再加入 `MainForm` 的 `ToolHostPage("批处理", …)` 数组。

重新运行 `build.ps1` 即可。
